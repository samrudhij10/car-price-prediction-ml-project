car-price-prediction-ml-project

This project predicts car selling prices using multiple Machine Learning regression algorithms.

 # Algorithms Used

- Linear Regression
- Lasso Regression
- Decision Tree Regressor
- Random Forest Regressor
- KNN Regressor

# Libraries Used

- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

# Project Workflow

1. Data Cleaning
2. Feature Engineering
3. One-Hot Encoding
4. Feature Scaling
5. Model Training
6. Model Comparison
7. Data Visualization

# Visualizations

- Correlation Heatmap
- Model Comparison Graph

# Conclusion

Random Forest performed best for car price prediction.
